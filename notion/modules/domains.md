# Domains

Group Areas by work or life context. Domains are optional and off by default (0055); an Org remains a separate organization.

## Turning it on

1. **Notion AI**, on Brain Data: create a full-page database "Domains" with Name (title), Summary (text), Lifecycle (select: Draft, Reviewed, Disputed, Archived), Archived (checkbox), Brain ID (text), Last Synced (date).
2. **Agent:** create two-way Areas · Domain ↔ Domains · Areas; with Orgs on, create Domains · Org ↔ Orgs · Domains. Record the database id in `notion.databases.domains`.
3. **By hand:** set Areas · Domain to Limit: 1 page. Group Home's Areas view by Domain, including No domain; show Domain on area homes and Areas and Org on Domain pages.
4. **Verify:** `brain modules` shows Domains on and its database configured; an Area can have one Domain or none.

## Turning it off

Run `brain modules off domains`. Domain notes and databases remain; the brain stops reading and publishing Domains and their Area relation. Hide the Domain grouping and database if desired.
