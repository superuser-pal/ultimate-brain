# Prompt 8 — Navigation

Paste into Notion AI. Before: [Prompt 7](07-spaces-views.md). Afterwards: "After building" in [../CHECKLIST.md](../CHECKLIST.md).

Two tiers of synced navigation, edited once on "System" and shown on every Space (docs/notion-space-design.md §5).

```text
On the page "System", create:
1. A synced block "Tier 1 nav" containing one line of links: Home · Plan · Projects · Meetings · Review · Knowledge. No colors or icons.
2. One synced block per Space named "Tier 2 nav – <Space>", each listing that Space's view names as links, with its own icon and background color.

Then on Home and on each Space page, place in a narrow left column: the "Tier 1 nav" synced block, a divider, then that Space's "Tier 2 nav" synced block (Home only gets Tier 1). Add a small plain-text label above each page's title with the page name.
```

## Verify
- [ ] Edit "Tier 1 nav" on System: the change appears on Home and every Space.
- [ ] Each Space shows Tier 1, a divider, then its own Tier 2 block; Home shows only Tier 1.
- [ ] Each Tier 2 link opens the matching view.
