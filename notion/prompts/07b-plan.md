# Prompt 7b — Plan Space views

Paste into Notion AI **while you are on the "Plan" page**, after [Prompt 6](06-templates.md). Other Spaces: [index](07-spaces-views.md).

This page holds only linked views of databases on "Brain Data". No navigation or layout work is in this prompt.

```text
On this page ("Plan") add:

1. A linked view of "Goals", Gallery layout with medium cards, named "What am I working toward?": filter Status is Active and Archived is unchecked; sort Deadline ascending; show Name, Progress (as a bar with the number), Deadline, Area.
2. A linked view of "Key Results", Table layout, named "How are my key results moving?": group by Goal; sort Due ascending; show Name, Kind, Current, Target, Unit, Progress (as a bar), Due, Done. If you can filter on the related Goal, filter Goal Status is Active; otherwise filter Done is unchecked.
3. A linked view of "Areas", List layout, named "Which areas do I own?": filter Archived is unchecked; sort Type then Name; show Name, Type, Summary.
4. A linked view of "Projects", Board layout, named "Which projects serve each goal?": group by Goal (show the empty group as "No goal"); filter Archived is unchecked and Status is not Done; sort Priority high to low; show Name, Status, Priority.

Rules: only add linked views of the existing databases on "Brain Data"; never create a new database on this page. Name each view exactly as written, question mark included. In every view hide the properties "Brain ID" and "Last Synced". Show only the properties listed. Do not add other content.
```

## Verify
- [ ] Only four linked views are on the page.
- [ ] Progress shows as a bar in views 1 and 2.
- [ ] View 4 has a "No goal" group (empty for now).
