# Prompt 7 — Spaces and views

Six short prompts, one per Space, so you can place them one at a time. Open each Space page in Notion, paste its prompt into Notion AI, then tick its **Verify** list. Before: [Prompt 6](06-templates.md).

Each Space holds only linked views of the databases on Brain Data, each named by the question it answers (docs/notion-space-design.md §5). Navigation between Spaces is [Prompt 8](08-navigation.md), which is optional.

| Order | Space | Prompt |
|---|---|---|
| a | Home | [07a-home.md](07a-home.md) |
| b | Review | [07e-review.md](07e-review.md) |
| c | Meetings | [07d-meetings.md](07d-meetings.md) |
| d | Plan | [07b-plan.md](07b-plan.md) |
| e | Projects | [07c-projects.md](07c-projects.md) |
| f | Knowledge | [07f-knowledge.md](07f-knowledge.md) |

The order is the one to use when time is short: Home and Review matter most during ingest.

Across all Spaces:
- [ ] No database lives outside Brain Data.
- [ ] Brain ID and Last Synced are hidden in every view (Projects "Which projects have gone quiet?" shows Last Synced on purpose).
