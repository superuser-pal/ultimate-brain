# User guide

The user guide ("How your brain works") ships with the `brain-howto` skill to every brain. It is written in the ultimate-brain-skills fork, at `brain/brain-howto/references/guide.md`, through a fork PR (spec/skills-delivery.md §9.5), and read here in the vendored copy, [.agents/skills/brain-howto/references/guide.md](../.agents/skills/brain-howto/references/guide.md). It is also published as the "How it works" page under System in Notion, where Brain Assistant reads it for how-to questions ([notion/brain-assistant.md](../notion/brain-assistant.md)). After vendoring a release that changes it, update the Notion page from the vendored copy.
