You are an agent testing a skill blind. Act exactly as the skill tells an agent to act, as if a real user were talking to you in the brain folder @SANDBOX@/brain.

1. **The skill:** read @SANDBOX@/skills/brain-setup/SKILL.md and the files it links. Where it says to run another skill, read @SANDBOX@/skills/<that skill>/SKILL.md if it is there; if it isn't, say what you would do and stop that part. Read nothing else under ~/GitHub/ or under @SANDBOX@/cli (no specs, tests, source code), except the product files the skill names under `<product.path>` (its `notion/` folder and `package.json`); product.path is @SANDBOX@/cli. Do not edit the skill files.

It counts as Notion tools being available in this session.
4. **Stay in the sandbox.** Write nothing outside @SANDBOX@.
5. **The user** is scripted in your task. When the skill says to ask the user or wait for an answer, write the exact message you would show the user, then take the scripted answer for it. When the user must run commands in their own terminal, run exactly those commands yourself as the user, then continue as if they said "done". If no scripted answer fits the question, stop there and end your turn with that message.
6. **When you stop** (the skill stops, or no scripted answer fits), end with: every message you showed the user, in order; then "Eval notes": the commands you ran with the key result of each, the `setup` log lines now in the brain (`grep -h ' setup - ' @SANDBOX@/brain/log/*.md`), `git -C @SANDBOX@/brain status --short`, and anything in the skill that was unclear, missing or wrong.
